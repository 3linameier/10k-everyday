Seadista automaatne logimine Apple Healthist

See saadab su sammude arvu otse Terviseäpist tulemustabelisse — pole vaja seda lehte avadagi. Töötab tasuta iOS-i otsetee (Shortcut) kaudu, vaikselt, kord päevas.

1 · Loo otsetee

  1. Ava rakendus Otseteed (Shortcuts) → puuduta ＋, et luua uus otsetee.
  2. Lisa toiming Find Health Samples → tüüp Steps, sorteeri alguskuupäeva järgi, filtreeri Start Date is Today.
  3. Lisa toiming Calculate Statistics → statistik Sum, eelmise sammu terviseandmete põhjal.
  4. Lisa toiming Get Contents of URL, seadistades selle allpool oleva järgi.

3 · Käivita see iga õhtu automaatselt

  1. Ava Otseteedes Automation → ＋ → Create Personal Automation → Time of Day (nt kell 21:00, iga päev).
  2. Lisa toiming Run Shortcut → vali äsja loodud otsetee.
  3. Lülita välja Ask Before Running, et see töötaks vaikselt.

Eelistad Health Auto Exporti?

Kui kasutad juba (tasulist) Health Auto Export äppi, saab see samamoodi omal ajakaval andmeid saata: Automations → REST API → kleebi ülalolev URL, meetod POST, lisa samad kaks päist ning seo väli steps tänase sammude summaga.

Tahad lihtsalt käsitsi sisestada?

Selleks ongi ülalolev vorm — seadistamist pole vaja, sobib kõigile.
